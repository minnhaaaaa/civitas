# Agent 8 handoff — audit viewer

Branch: `live/audit-viewer`

## Delivered

- Replaced the mock-only viewer path with `/audit/{signed-reference}` and real,
  paginated manifest, workflow-event, evidence-lineage, and execution-ledger
  retrieval.
- Added opaque HMAC-signed capabilities. PostgreSQL stores only the random
  reference hash plus organization, planning run, selected plan, maximum event
  sequence, issue/expiry, and revocation timestamps.
- Added signed cursors bound to the issuing link and requested resource. Links
  and cursors cannot be reused across organization scope or resource type.
- Added GET-only `/api/audit/{token}/...` resources to the existing MCP HTTP
  process. Only those signed GET paths bypass bearer auth; POST and the complete
  MCP approval/execution surface remain bearer-authenticated.
- Returned explicit projection contracts instead of ORM or raw JSON payloads.
  Raw evidence/provider payloads, credentials, workflow checkpoints,
  correlation IDs, approval challenges, and provider execution references are
  absent from viewer responses.
- Wired decision summaries to asynchronously issue a link for the persisted
  solver-selected plan and the checkpoint event boundary.
- Added production configuration validation: links are opt-in, TTL-bounded,
  HTTPS-only in production, and use a secret independent from bearer and
  approval secrets.
- Added an optional frozen-lockfile React/nginx image, Compose profile,
  Kubernetes example, no-store/referrer/CSP headers, and deployment guidance.
  The viewer is read-only and never participates in planning, approval, or
  execution availability.

## Database and runtime

- Alembic head: `e84b7c9d103f`
- Readiness expected revision was updated to the same head.
- Required when enabled:
  - `CIVITAS_AUDIT_VIEWER_ENABLED=true`
  - `CIVITAS_AUDIT_VIEWER_BASE_URL=https://...` in production
  - `CIVITAS_AUDIT_LINK_SECRET` with at least 32 independently generated bytes
  - optional `CIVITAS_AUDIT_LINK_TTL_SECONDS` (60 seconds to seven days; default
    900 seconds)

The capability is a bearer secret. Do not put audit URLs in analytics,
referrers, application logs, or support tickets. `revoked_at` supports an
organization-owned administrative revocation process; no public revocation or
write API was introduced.
